# Scholarship & Career Information Recommender
## Vision Statement

학교 홈페이지에 올라오는 장학금 및 취업 정보를 학생이 놓치지 않도록, 학생 정보를 기반으로 맞춤형 혜택 정보를 추천해주는 시스템이다.
학생은 자신의 학과, 학년, 성적, 관심 분야 등의 정보를 입력하고, 이에 맞는 장학 정보나 취업 정보를 추천받을 수 있다.

1. Target Users: 대학생, 학교 취업·장학 담당자

2. Problem/Need: 학교 홈페이지에 많은 정보가 올라오지만 학생들이 이를 모두 확인하기 어렵고, 본인에게 해당되는 정보를 놓치는 경우가 많음

3. Product Name/Category: Scholarship & Career Information Recommender / 교내 정보 추천 시스템

4. Key Benefit: 학생 맞춤형 장학·취업 정보 제공, 정보 탐색 시간 절감, 혜택 누락 방지

5. Differentiation: 단순 공지 조회가 아니라 학생 조건에 맞는 정보를 선별해서 추천해준다는 점

## Project Goals & Scope

### Business Goals
+ 학생 맞춤형 장학 및 취업 정보 추천 제공
+ 학생의 정보 탐색 부담 감소
+ 유용한 교내 공지의 활용도 향상
### In-Scope
+ 학생 정보 입력 및 저장
+ 장학 / 취업 공지 데이터 수집 및 관리
+ 사용자 조건 기반 추천 기능
+ 추천 결과 조회 기능
### Out-of-Scope
+ 외부 채용 플랫폼 연동
+ 실시간 푸시 알림 앱 개발
+ AI 기반 고도화 추천
## Stakeholders & Users
+ 학생: 자신에게 해당되는 장학금이나 취업 정보를 쉽게 찾고 싶음
+ 관리자: 공지 정보를 효율적으로 관리하고 학생에게 잘 전달하고 싶음
+ 개발자: 학생 정보와 공지 데이터를 안정적으로 매칭할 수 있어야 함
+ 테스터: 추천 결과의 정확성과 예외 상황을 검증해야 함


## Milestones
+ 요구사항 분석 및 데이터 구조 설계
+ 학생 정보 입력 및 공지 데이터 관리 기능 구현
+ 장학 / 취업 정보 추천 로직 구현
+ 추천 결과 조회 및 관리자 기능 구현
+ 통합 테스트 및 UI 연동
+ 최종 발표 및 문서화
